# Programming with Python - Assignment 1

**Course:** Programming with Python (202044504)
**Program:** B.Tech. Information Technology, Semester V

## About

This repository contains the Python solutions for **Assignment 1**. The assignment focuses on problem solving using Python concepts such as data structures, recursion, exception handling, OOP, file handling, graphs, multithreading and Tkinter.

## Questions Covered

1. **Campus Merit Analyzer**
   Lists, tuples, dictionaries, sorting and data aggregation.

2. **Optimized Password Audit**
   Password validation, pattern checking and banned-word detection.

3. **Recursive Expression Engine**
   Expression evaluation, recursion, memoization and cycle detection.

4. **CSV Transaction Splitter**
   CSV file handling, validation, exception handling and account-wise calculations.

5. **Object-Oriented Bank Settlement System**
   Classes, transactions, custom exceptions and batch rollback.

6. **Python Module Dependency Resolver**
   Graphs, dependency resolution, topological sorting and cycle detection.

7. **Interactive Formula Validator**
   Custom exceptions, variables, parsing and calculator operations.

8. **Compressed Log Index**
   File handling, text processing, pickle, ZIP compression and inverted indexing.

9. **Threaded Job Scheduler**
   Job scheduling, priority queues, worker simulation and execution reports.

10. **Tkinter Assignment Tracker**
    GUI development, event handling, JSON persistence and CSV export.

## Requirements

* Python **3.10 or above**
* Tkinter for Q10
* No external libraries are required for the other programs.

## How to Run

Navigate to the folder containing the required Python file and run:

```bash
python filename.py
```

Follow the input prompts or provide the input according to the question's specified format.
